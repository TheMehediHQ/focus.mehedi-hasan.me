# focus.mehedi-hasan.me — Modern Deep Work & Meditation Music Workspace

A distraction-free, ultra-modern web sanctuary designed for deep concentration, meditation, study, and flow state. Built with **Astro 5**, **React 18**, **TypeScript**, and **Tailwind CSS**.

---

## Features

- **Modern Minimalist Dashboard**:
  - Digital monospace live clock with pulsing cyan separator and date badge.
  - Contextual time-of-day greeting.
  - Curated rotating mindful thoughts.
  - "Start Focus" one-click action button.

- **High-Precision Focus Timer**:
  - **25m Pomodoro**, **50m Focus**, **90m Deep Work**, and **Custom Duration** (1–360 minutes).
  - Glowing circular SVG countdown ring with millisecond accuracy.
  - Start, pause, resume, reset, and quick `+5m` extension.
  - Soft chime on session completion with celebratory confetti.

- **6 Exclusive Master Soundscapes**:
  1. **নিঃসীম নীলিমায় (In the Boundless Blue)** — Deep Focus (48m 03s, Alpha-Theta Expansion)
  2. **আত্মার আলোর ছোঁয়া (Touch of the Soul's Light)** — Meditation (67m 54s, 432Hz Spiritual Healing)
  3. **মেডিটেশন মিউজিক: নব জাগরণ (New Awakening)** — Meditation (66m 52s, 528Hz Transformation)
  4. **মেঘের স্নিগ্ধ সুর (Gentle Cloud Melodies)** — Rain Sounds (72m 18s, Atmospheric Cloud Harmony)
  5. **প্রকৃতির প্রতিধ্বনি (Echo of Nature)** — Nature & Forest (100m 20s, Organic Forest Resonance)
  6. **শুভ্রতার আলো (Light of Purity & Serenity)** — Piano & Ambient (88m 08s, Pure Solfeggio Resonance)

- **Sleek Floating Audio Dock**:
  - Custom HTML5 audio player with animated equalizer bars when playing.
  - Interactive scrubber progress bar with hover time tooltip.
  - Repeat modes (`off`, `all`, `one`), shuffle, volume slider with mute toggle.
  - MediaSession API integration for OS media keys & lockscreen controls.
  - Fullscreen distraction-free focus mode (`F`).

- **Keyboard Shortcuts**:
  - `Space` — Play / Pause audio
  - `→` / `←` — Next / Previous track
  - `↑` / `↓` — Volume Up / Down (+/- 5%)
  - `M` — Mute / Unmute audio
  - `F` — Toggle Fullscreen Focus Mode
  - `T` — Start / Pause Focus Timer
  - `R` — Reset Timer
  - `?` (`Shift + /`) — View Keyboard Shortcuts
  - `Esc` — Close dialogs or exit fullscreen
